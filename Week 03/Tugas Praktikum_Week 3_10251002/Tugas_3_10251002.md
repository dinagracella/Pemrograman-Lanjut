3. Access Modifier
- Pada class Perangkat dan Mahasiswa, atribut dibuat private agar data tidak dapat diakses atau diubah secara langsung dari luar class.
- Pada class Perangkat, setKodeProduk() dan setStok() dibuat private karena data harus melewati validasi sebelum disimpan. Sementara itu, getKodeProduk() dan getStok() dibuat public agar data dapat dibaca dari luar class.
- Pada class Mahasiswa, setNim() dibuat private karena NIM hanya diisi melalui constructor. Sedangkan setNama() dan setIpk() dibuat public karena nama dan IPK dapat diubah setelah objek dibuat, tetapi tetap melalui validasi. Getter getNim(), getNama(), dan getIpk() dibuat public agar data dapat dibaca dari luar class.
- Penggunaan private dan public ini menerapkan konsep encapsulation, yaitu membatasi akses langsung terhadap data dan memastikan data diproses melalui aturan yang telah ditentukan.
